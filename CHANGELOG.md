# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and versions are named in the format `1.0.0`, without the leading `v` prefix.

## 1.0.0

### Added
- Initial release of Neikiri's SA-MP CW/TG Gamemode
- Two-team CW/TG gameplay system with Green and Blue teams
- Round-based scoring and match flow
- Team kill detection and score tracking
- Spectator mode and player HUD elements
- Skin selection and validation against banned speed skins
- Weather, time, and virtual world controls
- SQLite-based admin, user, and ban management
- Admin command system with levels from 0 to 5
- NPC management commands for server-side NPC support
- Server lock/password support
- Basic vehicle spawn and cleanup commands
- End-of-round result screens and team score updates

### Changed
- Initial project structure and gamemode setup for SA-MP
- Standardized server configuration and documentation around the gamemode

### Fixed
- Initial project baseline established for stable gameplay flow and admin management
